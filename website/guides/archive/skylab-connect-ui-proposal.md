# SkyLab Connect — 介面提案

獨立的互動 HTML demo，參考 Web 端「我的資源」與首頁機器卡的品牌色、資源分類、狀態及終端資訊呈現。沒有連接正式 API，也不會建立 VPN、執行 SSH 或修改 APP 設定。

## 預覽

在這個目錄執行 `python -m http.server 8768 --bind 127.0.0.1`，開啟 <http://127.0.0.1:8768/>。也可以直接開啟 `index.html`；複製指令功能可能需要 localhost 的安全環境。

## 可操作的內容

- 深色／亮色主題。
- 全部、課程及個人資源篩選，名稱、IP 與 VMID 搜尋。
- 卡片／列表顯示。
- 頂端狀態選單：已連線、未連線、連線中、失敗。
- 模擬開始／中斷連線，SSH 按鈕隨狀態啟用或停用。
- SSH 指令預覽、帳號輸入與複製；已到期機器保持停用。
- 機器詳情、連線資訊及外觀設定。

資料沿用問題截圖中的三台機器作為示例。示範的「已連線」不代表實際 WireGuard handshake；整合正式版時應使用已驗證的連線狀態。

此目錄保留最初的互動設計提案；正式 APP 介面已實作於 `desktop-client/src/views/home`，以實際資源、Tunnel 狀態及 SSH／RDP 操作為準。
