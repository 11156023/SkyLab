# 儲存空間

儲存空間列出從各 PVE 連線同步回來的 Storage，讓管理員決定平台可以把新機器的磁碟放在哪些 Storage、以及優先順序。建立機器時，放置演算法會依這裡的啟用狀態、速度等級與優先度挑選存放磁碟的 Storage。側欄：管理員設定 → 儲存空間。路徑：`/storage`。

## 誰可以使用

只有管理員。這頁位於管理員設定的側欄中，其他人無法讀取或修改 Storage 設定。

## 開始之前

- 清單來自最近一次同步。要在 [PVE 管理](/zh-TW/manual/pve-connections) 頁按**同步**，Storage 才會出現或更新；這頁不會直接讀取 PVE。
- 還沒同步過時，頁面會顯示**尚無 Storage 設定**。

## 操作步驟

### 找到 Storage

1. 用上方的切換：**全部**、**啟用**或**停用**。按鈕上的數字是各狀態的數量。
2. 在搜尋框（**搜尋名稱、節點或類型**）輸入關鍵字，可比對 Storage 名稱、所在節點（共享 Storage 比對所有節點）、連線名稱與類型。
3. 找不到時會顯示**找不到 Storage**，並提供清除篩選的按鈕。

![找到 Storage（圖中編號對應上方步驟）](/manual-shots/zh-TW/storage/s01.webp)

### 看懂 Storage 列

1. 第一行是 Storage 名稱與所在位置：
   - 只在單一節點上的 Storage 會標出節點；
   - 共享 Storage 顯示**共享 · N 節點**，滑過可以看到節點名稱；
   - 有多組 PVE 連線時，會再加上連線名稱的標籤。
2. 第二行是類型、已用／總容量（GB）與用途：**VM**、**LXC**、**ISO**、**Backup**，沒有用途時顯示**無用途**。
3. 只有標示 **VM** 的 Storage 會被選來放虛擬機磁碟，只有標示 **LXC** 的 Storage 會被選來放容器磁碟。

![看懂 Storage 列（圖中編號對應上方步驟）](/manual-shots/zh-TW/storage/s02.webp)

### 設定速度等級

1. 在該列的**速度等級**選擇 **NVMe**、**SSD**、**HDD** 或**未知**。
2. 選了就立即儲存，並提示「… 已更新」。
3. 放置時先比較速度等級（NVMe → SSD → HDD → 未知），再比較使用率。同步進來的新 Storage 預設是**未知**，每次同步新增 Storage 後記得改成正確等級。

![設定速度等級（圖中編號對應上方步驟）](/manual-shots/zh-TW/storage/s03.webp)

### 設定使用者優先度

1. 在**使用者優先度**輸入 1～10 的整數，數字越小越優先。
2. 按 Enter 或點其他地方才會儲存，輸入過程中不會存檔。
3. 超出 1～10、空白或小數都會還原成已儲存的值；儲存失敗時也會還原。
4. 優先度只在速度等級與使用率都差不多時用來決勝。

![設定使用者優先度（圖中編號對應上方步驟）](/manual-shots/zh-TW/storage/s04.webp)

### 啟用或停用 Storage

1. 勾選或取消勾選該列的**啟用**，變更會立即儲存。
2. 停用的 Storage 不會再被選來放新機器的磁碟。

![啟用或停用 Storage（圖中編號對應上方步驟）](/manual-shots/zh-TW/storage/s05.webp)

### 修改共享 Storage

1. 在共享 Storage 的列上照常修改速度等級、優先度或**啟用**。
2. 變更會套用到該叢集中所有掛載這個 Storage 的節點，提示訊息會寫出套用了幾個節點（「… 已更新（套用至 N 個節點）」）。

![修改共享 Storage（圖中編號對應上方步驟）](/manual-shots/zh-TW/storage/s06.webp)

## 欄位與選項

| 欄位 | 意義 | 備註 |
| --- | --- | --- |
| 速度等級 | NVMe、SSD、HDD 或未知 | 最先比較；新 Storage 預設為未知 |
| 使用者優先度 | 1～10，越小越優先 | 只用來決勝；按 Enter 或離開欄位時儲存 |
| 啟用 | 放置演算法能否使用這個 Storage | 立即儲存 |
| 用途 | PVE 回報的 VM、LXC、ISO、Backup | 只有 VM／LXC 的 Storage 會放機器磁碟 |
| 共享 · N 節點 | 掛載在同一叢集多個節點上的 Storage | 每個叢集只列一筆；變更套用到所有節點 |
| 已用／總容量 | 最近一次同步時的容量（GB） | 在 PVE 管理按同步更新 |

## 限制與注意事項

- 容量數字與 Storage 清單只會反映 PVE 管理上最近一次**同步**的結果。
- 每次修改都會寫入稽核日誌。
- 機器能不能使用快照由 PVE 決定，並在每台機器的詳情頁即時檢查；這頁不會改變這件事。不能使用快照的機器，若該連線在 PVE 管理設定了備份 storage，詳情頁會改提供備份。
