# 使用手冊

網頁介面的每個功能一頁，寫給實際操作的人。每一頁的結構相同：這頁做什麼、誰能開、逐步操作、欄位與選項、會遇到的限制。介面文字照畫面上的原文引用。

依你的角色選擇：

## 學生

從第一次登入到拿到一台能用的機器。

- [登入](/zh-TW/manual/login)：密碼、Google 或 LDAP 登入、兩步驟驗證、服務檢查、首次登入導覽
- [首頁](/zh-TW/manual/home)：各角色的首頁顯示什麼
- [帳號設定](/zh-TW/manual/account)：個人資料、密碼、兩步驟驗證、外觀、關於
- [我的申請](/zh-TW/manual/my-requests)：申請表單、使用時段、配額、申請單狀態
- [我的資源](/zh-TW/manual/my-resources)：你的機器清單、主控台與電源操作
- [資源詳情](/zh-TW/manual/resource-detail)：登入資料、監控、調整規格、快照、備份、防火牆、延期、密碼、共享
- [防火牆](/zh-TW/manual/firewall)：自己機器的規則，以及看得到別人的哪些部分
- [快速練習](/zh-TW/manual/quick-practice)：不用申請就啟動老師發布的環境
- [課程](/zh-TW/manual/courses)：每週內容、實驗機、進度
- [AI API](/zh-TW/manual/ai-api)：申請與使用 `ccai_*` 金鑰

## 老師

學生能做的全部，再加上：

- [機器範本](/zh-TW/manual/templates)：把準備好的機器轉成平台範本
- [建立班級](/zh-TW/manual/class-setup)：名單、課表、環境、批次建置
- [班級管理](/zh-TW/manual/class-management)：班級清單、草稿與批量封存
- [班級工作頁](/zh-TW/manual/class-workspace)：學生、機器、監看、廣播、每週內容
- [AI導師檢查](/zh-TW/manual/ai-judge)：檢查表、產生腳本、在學生機器上執行檢查
- [教學環境](/zh-TW/manual/course-templates)：建構與發布多機拓樸，另見 [SOP](/zh-TW/guides/multi-machine-environment-sop)
- [課程管理](/zh-TW/manual/course-cms)：學習路徑、任務與題目

## 管理員

以上全部，再加上平台本身：

- 平台：[使用者管理](/zh-TW/manual/admin-users)、[PVE 管理](/zh-TW/manual/pve-connections)、[IP 管理](/zh-TW/manual/ip-management)、[閘道 VM](/zh-TW/manual/gateway)、[網域管理](/zh-TW/manual/domain)、[LDAP](/zh-TW/manual/ldap)
- 政策：[資源排程](/zh-TW/manual/scheduler)、[資源政策](/zh-TW/manual/governance)（欄位參考：[治理設定欄位](/zh-TW/reference/governance-config)）
- 容量：[儲存空間](/zh-TW/manual/storage)、[GPU 管理](/zh-TW/manual/gpu-management)
- 審核與維運：[資源管理](/zh-TW/manual/resource-management)、[申請審核](/zh-TW/manual/request-review)、[班級審核](/zh-TW/manual/batch-review)、[資源監控](/zh-TW/manual/monitoring)、[背景任務](/zh-TW/manual/jobs)、[稽核日誌](/zh-TW/manual/audit)
- AI：[AI API 審核](/zh-TW/manual/ai-api-review)、[金鑰管理](/zh-TW/manual/ai-api-keys)、[AI 用量監控](/zh-TW/manual/ai-monitoring)

安裝與維運伺服器見[快速開始](/zh-TW/getting-started)與「維運」區（[部署指南](/zh-TW/guides/deployment)、[升級](/zh-TW/operations/upgrade)、[備份](/zh-TW/operations/backup)、[系統監控](/zh-TW/guides/monitoring)）。
