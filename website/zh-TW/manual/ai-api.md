# AI API

申請屬於自己的 API 金鑰，用任何相容 OpenAI 的用戶端在自己的程式裡呼叫校園 AI 模型，或直接在瀏覽器裡和模型對話。側欄：AI 服務 → AI API。路徑：`/ai-api`。

## 誰可以使用

所有登入的使用者：學生、老師與管理員。每個人只看得到自己的金鑰、申請與用量。不同身分唯一的差別是可以申請的金鑰有效期限（見下方「欄位與選項」）。

## 開始之前

- 金鑰要等管理員核准申請後才會發放，請預留審核時間。
- 金鑰以 `ccai_` 開頭。請把金鑰當成密碼保管：不要貼進作業、截圖或公開的程式碼庫。

## 操作步驟

### 申請金鑰

1. 按 **申請金鑰**（在右上角；分頁沒有內容時也會出現在中央）。
2. 填寫 **金鑰名稱**，例如課程或專題名稱。它只是給你自己辨識的標籤，之後可以改名。
3. 在 **申請目的** 寫至少 10 個字，說明是哪門課或哪個專題、打算做什麼。審核者會看這段文字。
4. 選擇 **金鑰有效期限**。
5. 按 **送出申請**。對話框會關閉並切到 **申請紀錄** 分頁，申請狀態顯示 **待審核**。

![申請金鑰（圖中編號對應上方步驟）](/manual-shots/zh-TW/ai-api/s01.webp)

### 等待審核

1. 可以開著這一頁，也可以晚點再回來。有待審的申請時，頁面會自動更新，核准或拒絕時會跳出提示。
2. **已通過**：金鑰會出現在 **API 金鑰** 分頁，狀態為 **使用中**。有效期限從核准的那一刻開始計算。
3. **已拒絕**：到 **申請紀錄** 看 **審核意見**，調整申請目的後重新申請。

![等待審核（圖中編號對應上方步驟）](/manual-shots/zh-TW/ai-api/s02.webp)

### 查看並複製金鑰

1. 打開 **API 金鑰** 分頁。清單只顯示金鑰的開頭幾個字元。
2. 點有底線的金鑰名稱，開啟 **API Key 詳細資料**。
3. 用 **API Key**、**金鑰名稱** 與 **Base URL** 旁的複製按鈕複製。
4. **複製 cURL 指令** 會複製一行已填好你的金鑰、可直接執行的指令，用來列出可用的模型。在終端機執行它，就能確認金鑰可以用。

詳細資料也會顯示金鑰的 **狀態**、**建立時間**、**到期時間** 與 **速率限制**（每分鐘次數）。只有 **使用中** 的金鑰會顯示完整金鑰。

![查看並複製金鑰（圖中編號對應上方步驟）](/manual-shots/zh-TW/ai-api/s03.webp)

### 用「API 快速開始」送出第一個請求

1. 按 **API 快速開始**。
2. **複製連線資訊**：複製 **Base URL** 與 **API Key**。有多把可用的金鑰時，先選擇要用哪一把。
3. **查可用的模型**：複製指令並執行。回傳結果裡每個模型的 `id` 就是程式裡要填的模型名稱。
4. **執行範例**：選擇 API 類型（**Responses** 或 **Chat Completions**）與程式語言（**JavaScript**、**Python**、**Bash（macOS／Linux）** 或 **CMD（Windows）**），複製程式碼後把 `YOUR_API_KEY`、`MODEL_NAME` 與 `INPUT` 換成實際的值。
5. 呼叫失敗時，打開最下方的 **遇到錯誤？**，查看 401、429、413 與 502 的意思。

Base URL 以 `/api/v1/ai-proxy` 結尾。範例使用官方的 OpenAI SDK，所以任何相容 OpenAI 的工具都能用同一組 Base URL 與金鑰。更多 curl 範例請看 [AI API 使用手冊](/zh-TW/guides/ai-api-user-manual)。

![用「API 快速開始」送出第一個請求（圖中編號對應上方步驟）](/manual-shots/zh-TW/ai-api/s04.webp)

### 在瀏覽器裡和模型對話

1. 打開 **API 聊天** 分頁。它使用你自己可用的金鑰。
2. 選擇模型。有多把可用的金鑰時，也可以選擇要用哪一把。
3. 輸入問題後按 Enter（Shift + Enter 換行），或按 **送出**。回覆會即時顯示，按 **停止等待** 可以中止。
4. 按 **新對話** 重新開始。之前的對話列在 **本機對話** 下，點一下可以重新打開，按刪除圖示可以刪除。

如果你沒有可用的金鑰，這個分頁會出現 **Campus API 金鑰** 欄位，可以貼上金鑰後按 **套用金鑰**。

對話只保存在目前的瀏覽器，不會同步到其他裝置，清除瀏覽資料後就會消失。在這裡發出的呼叫和其他呼叫一樣計入你的用量。

![在瀏覽器裡和模型對話（圖中編號對應上方步驟）](/manual-shots/zh-TW/ai-api/s05.webp)

### 重新命名金鑰

1. 在 **API 金鑰** 打開該金鑰的 **⋮** 選單，選 **重新命名**。
2. 輸入新名稱後按 Enter（或按勾勾）。按 Esc 取消。

![重新命名金鑰（圖中編號對應上方步驟）](/manual-shots/zh-TW/ai-api/s06.webp)

### 重新產生金鑰

1. 打開 **⋮** 選單，選 **重新產生金鑰**。
2. 按 **重新產生** 確認。舊金鑰會立即失效。
3. 詳細資料對話框會顯示新金鑰，請把程式裡的金鑰換成新的。

新金鑰沿用原本的名稱、速率限制與到期時間。已過期的金鑰不能重新產生，請重新申請。

![重新產生金鑰（圖中編號對應上方步驟）](/manual-shots/zh-TW/ai-api/s07.webp)

### 刪除金鑰

1. 打開 **⋮** 選單，選 **刪除**。
2. 按 **刪除** 確認。

金鑰會從你的清單消失，之後用它發出的新呼叫會立即失敗。已經被接受的呼叫會完成並記錄用量。

![刪除金鑰（圖中編號對應上方步驟）](/manual-shots/zh-TW/ai-api/s08.webp)

### 查看已失效的金鑰

已經不能用的金鑰會收在表格下方。按 **顯示已失效的金鑰（n）** 展開，按 **收起已失效的金鑰** 收合。

![查看已失效的金鑰](/manual-shots/zh-TW/ai-api/s09.webp)

### 查看用量

1. 打開 **我的用量** 分頁。
2. 選擇 **7 天**、**30 天** 或 **90 天**，切換鈕旁會顯示實際涵蓋的日期。
3. **API 用量** 顯示 **總呼叫次數**、**輸入 Tokens** 與 **輸出 Tokens**，以及逐日 Tokens 用量圖與各模型的用量。
4. **細項紀錄** 依時間由新到舊列出每一次呼叫：**日期**、**模型**、**API Key 來源**、**輸入 Tokens**、**輸出 Tokens** 與 **狀態**。點一列可以看到 **Request ID**、**請求類型**、**總 Tokens**、**處理時間** 與錯誤訊息。
5. 按 **載入更多** 再載入 20 筆。

這裡只計算用你自己的金鑰發出的呼叫。

![查看用量（圖中編號對應上方步驟）](/manual-shots/zh-TW/ai-api/s10.webp)

## 欄位與選項

| 欄位 | 意義 | 說明 |
| --- | --- | --- |
| 金鑰名稱 | 用來分辨不同金鑰的標籤 | 必填，最多 20 字，之後可改名 |
| 申請目的 | 金鑰要拿來做什麼，審核者會看到 | 10 到 2000 字 |
| 金鑰有效期限 | 核准後金鑰可以使用多久 | 學生：1 天、7 天、30 天（預設）或 90 天。老師與管理員：1 天、7 天、30 天或永不過期（預設） |

**API 金鑰** 分頁的金鑰狀態：

| 狀態 | 意義 |
| --- | --- |
| 使用中 | 金鑰可以使用 |
| 已過期 | 已超過有效期限，請重新申請 |
| 已替換 | 金鑰重新產生過，已被新金鑰取代 |
| 已停用 | 金鑰已被撤銷，無法再發起新的呼叫 |

**申請紀錄** 的申請狀態：**待審核**、**已通過**、**已拒絕**。

## 限制與注意事項

- 同時最多只能有 3 筆待審核的申請。
- 每把金鑰都有每分鐘的速率限制，可在詳細資料查看（預設每分鐘 20 次）。超過時會回傳 429，請稍等再試。
- 請求內容太大會回傳 413；模型沒有回應會回傳 502。
- 金鑰到期後就不能再用，也不能重新產生；申請紀錄會保留。
- **API 金鑰** 分頁上的數字是可用金鑰的數量；**申請紀錄** 分頁上的數字是待審核的申請數。
- 管理員看得到你有哪些金鑰、最近一次使用時間，但看不到完整金鑰。
