# 課程管理

課程管理讓老師以「學習路徑 › 房間 › 任務」的樹狀結構編排班級的線上課程、在任務底下掛題目、把路徑發布給班上學生，並即時查看每位學生的進度。這個頁面沒有側欄入口，請直接輸入網址開啟。路徑：`/course-cms`（學生進度分頁是 `/course-cms?tab=progress`）。

## 誰可以使用

- **老師**：查看與編輯自己班級的學習路徑。
- **管理員**：查看與編輯所有學習路徑。
- 學生無法使用這個頁面，開啟網址會被導回首頁。

## 開始之前

- 先在[建立班級](/zh-TW/manual/class-setup)建好班級。每個班級都會自動建立一條與班級同名的學習路徑，所以大多數班級在這裡已經有路徑了。
- 一個班級只能連結一條學習路徑。

## 操作步驟

### 認識版面

1. 開啟 `/course-cms`，頁首有兩個分頁：**內容編輯**與**學生進度**。
2. 在**內容編輯**分頁，左邊是**課程內容**樹，右邊是選中項目的工作區。
3. 在樹裡點名稱選取、點箭頭展開或收合。房間與任務在展開上一層時才載入。

![認識版面（圖中編號對應上方步驟）](/manual-shots/zh-TW/course-cms/s01.webp)

### 新增學習路徑

1. 點**課程內容**旁的 **+**（樹是空的時候點**新增學習路徑**）。
2. 在**新增學習路徑**對話框選擇**所屬班級**。選單只列出還沒有路徑的班級；全部都有時會顯示**所有班級都已經有學習路徑，一個班級只能連結一條。**
3. 填寫**路徑名稱**。
4. 按**建立**，新路徑會自動被選取。

![新增學習路徑（圖中編號對應上方步驟）](/manual-shots/zh-TW/course-cms/s02.webp)

### 編輯學習路徑

1. 在樹裡選取路徑，工作區標示為**學習路徑**。
2. 修改**路徑名稱**後按**儲存**。
3. **發布狀態**會顯示**已發布，學生看得到**或**草稿，學生還看不到**。按**發布**或**下架**切換，立即生效。
4. 用**所屬班級**改連結到其他班級，或選**尚未連結**。已經有路徑的班級會呈灰色無法選取。這項設定也是立即生效。
5. **刪除路徑**經確認後會連同底下的房間與任務一起刪除。

![編輯學習路徑（圖中編號對應上方步驟）](/manual-shots/zh-TW/course-cms/s03.webp)

### 新增與編輯房間

1. 展開路徑，在房間清單最下面點**新增房間**。
2. 輸入房間標題後按 Enter（或點勾勾），按 Esc 取消。新房間會自動被選取。
3. 在工作區修改**房間名稱**與**難度**（**簡單**、**中等**、**困難**），再按**儲存**。
4. **刪除房間**經確認後刪除該房間。

![新增與編輯房間（圖中編號對應上方步驟）](/manual-shots/zh-TW/course-cms/s04.webp)

### 新增與編輯任務

1. 展開房間，在任務清單最下面點**新增任務**，輸入標題後按 Enter，新任務會自動被選取。
2. 在工作區編輯**任務標題**與**教學內容（Markdown）**。
3. 按**儲存任務**。
4. **刪除任務**經確認後刪除該任務。

![新增與編輯任務（圖中編號對應上方步驟）](/manual-shots/zh-TW/course-cms/s05.webp)

### 替任務加入題目

1. 選取任務，**題目**區塊會顯示目前的題數。
2. 按**新增題目**。
3. 選擇**題型**：
   - **答案題**：學生要輸入正確答案才算完成。
   - **閱讀題**：學生按下完成就算數，不用輸入答案。
4. 填寫**題目描述**。
5. 答案題要填**正確答案**。學生輸入的內容去掉前後空白後要完全一樣，大小寫也要相同。
6. 設定**分數**後按**建立**。
7. 要修改題目時，點清單中的那一題。已存的答案無法再顯示：**正確答案**留空代表沿用原答案，也可以輸入新的答案。改完按**儲存**。
8. 要刪除題目時，點該題的垃圾桶圖示並確認；學生在這一題的完成記錄會一併刪除。

![替任務加入題目（圖中編號對應上方步驟）](/manual-shots/zh-TW/course-cms/s06.webp)

### 查看學生進度

1. 切到**學生進度**分頁。
2. 從**選擇學習路徑…**選一條路徑。
3. 旁邊的標記顯示**即時更新中**時，學生一作答報表就會在短時間內自動刷新；顯示**連線中斷**時數字可能不是最新的，頁面會自動重新連線。
4. 表格列出每位**學生**（姓名與 Email）、整條路徑的**總進度**百分比，以及每個房間一欄的「已完成題數／總題數」。
5. 還沒有人作答時會顯示**尚無作答紀錄**。

![查看學生進度（圖中編號對應上方步驟）](/manual-shots/zh-TW/course-cms/s07.webp)

## 欄位與選項

| 欄位 | 意義 | 備註 |
| --- | --- | --- |
| 路徑名稱 | 學習路徑的標題 | 必填，最多 255 字 |
| 所屬班級 | 哪個班級的學生看得到這條路徑 | 一個班級一條路徑 |
| 發布狀態 | 學生看不看得到這條路徑 | **發布**／**下架**，立即生效 |
| 房間名稱 | 房間的標題 | 必填，最多 255 字 |
| 難度 | 房間難度 | **簡單**、**中等**、**困難**；新房間預設為**簡單** |
| 任務標題 | 任務的標題 | 必填，最多 255 字 |
| 教學內容（Markdown） | 任務的內文 | 按**儲存任務**才會存檔 |
| 題型 | 題目怎麼算完成 | **答案題**或**閱讀題** |
| 題目描述 | 題目文字 | 必填，最多 1000 字 |
| 正確答案 | 學生必須輸入的答案 | 最多 500 字；新增答案題時必填 |
| 分數 | 這一題的分數 | 0～1000，預設 10 |

## 限制與注意事項

- 名稱、難度與教學內容要按**儲存**（或**儲存任務**）才會送出；有未儲存的修改時，按鈕旁會顯示**尚未儲存**。
- 有未儲存的修改時，選取其他項目、切換分頁或離開頁面都會先請你確認。
- **發布**／**下架**、**所屬班級**與題目的操作按下就生效。
- 草稿狀態的路徑學生看不到。發布後，所屬班級的學生會在[課程](/zh-TW/manual/courses)看到這門課，課程票券上也會顯示題數。
- 刪除路徑會連同房間與任務一起刪除；刪除題目會連同學生的完成記錄一起刪除，兩者都無法復原。
