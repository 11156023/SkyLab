# IP 管理

IP 管理保存機器子網的設定，每台 VM 與 LXC 的固定 IP 都從這裡配發；頁面也列出子網內每個已被使用的位址與用途。側欄：管理員設定 → IP 管理。路徑：`/ip-management`。

## 誰可以使用

只有管理員。老師與學生看不到這一頁，他們的機器只會從這裡設定的子網自動拿到位址。

## 開始之前

- 先確認 PVE 端的實驗室網路：CIDR 格式的子網、子網的閘道位址、機器要接的 Linux bridge（例如 `vmbr1`），以及有使用時的 VLAN ID。
- 決定 Gateway VM 在這個子網內的位址。如果 SkyLab 主系統本身也在這個子網內，也記下它的位址，以免被配給機器。
- 子網尚未設定前，全站任何人都無法建立 VM 或 LXC。

## 操作步驟

### 建立子網設定

1. 開啟頁面。尚未設定時會顯示「尚未設定子網」。
2. 按「建立子網設定」。
3. 填寫「子網 CIDR」、「閘道 IP」、「Bridge 名稱」與「Gateway VM IP」，這四欄為必填。
4. 視需要填寫「VLAN ID」、「主系統 IP」、「DNS Servers」、對外 port 配號池、「對外入口主機」與「預設封鎖網段 / IP」（見下方表格）。
5. 按「建立設定」。出現「子網設定已儲存」提示後，平台就開始從新的子網配發位址。

![建立子網設定（圖中編號對應上方步驟）](/manual-shots/zh-TW/ip-management/s01.webp)

### 修改子網設定

1. 按頁首的「編輯子網設定」。
2. 修改需要的欄位後按「更新設定」。
3. 如果「子網 CIDR」是灰色無法編輯，代表網段已被使用（見「限制與注意事項」），滑鼠移上去可看原因。
4. 儲存時，封鎖網段會逐台套用到每台機器的防火牆。若有機器套用失敗，錯誤提示會列出失敗台數與 VMID，這些機器目前尚未被封鎖；請稍後重新儲存，或檢查 PVE 連線。

![修改子網設定（圖中編號對應上方步驟）](/manual-shots/zh-TW/ip-management/s02.webp)

### 刪除子網設定

1. 按「編輯子網設定」，再按「刪除子網設定」。
2. 按「刪除」確認。
3. 只有在沒有任何 VM／LXC 仍佔用 IP、也沒有班級或快速練習的預留時才能刪除。刪除後全站停用 VM／LXC 建立功能，直到重新建立子網設定。

![刪除子網設定（圖中編號對應上方步驟）](/manual-shots/zh-TW/ip-management/s03.webp)

### 查詢位址的使用者

1. 用搜尋框（「搜尋 IP、VMID 或備註」）篩選表格。
2. 搜尋框旁邊會顯示目前生效的子網、Bridge，以及有設定時的 VLAN。
3. 表格列出「IP 位址」、「用途」、「VMID」、「分配時間」與「備註」，每頁 50 筆，用「上一頁」、「下一頁」翻頁。

這張表只供查看。建立機器時自動配發位址，刪除機器後位址會自動釋放。

![查詢位址的使用者（圖中編號對應上方步驟）](/manual-shots/zh-TW/ip-management/s04.webp)

## 欄位與選項

| 欄位 | 意義 | 備註 |
| --- | --- | --- |
| 子網 CIDR | 機器取得位址的範圍，例如 `10.10.0.0/24` | 必填。前綴長度 `/8` 到 `/31`；不接受 `/32` |
| 閘道 IP | 子網的預設閘道 | 必填。必須在子網內 |
| Bridge 名稱 | 機器網卡要接的 PVE bridge | 必填。預設 `vmbr1` |
| VLAN ID | 機器網卡帶的 802.1Q tag | 選填，1–4094；留空表示不使用 VLAN。只套用到之後建立的機器 |
| Gateway VM IP | Gateway VM 的位址 | 必填。必須在子網內，且不能和閘道 IP 相同 |
| 主系統 IP | SkyLab 主系統在子網內的位址 | 選填。會被保留、不配給機器；平台也會在每台機器上維持一條允許此位址連 SSH（port 22）的規則，清空欄位時一併移除 |
| DNS Servers | 機器使用的 DNS | 選填，多組以逗號分隔，例如 `8.8.8.8,1.1.1.1` |
| 對外 port 配號池：起始／結束 | 教學環境的 port 轉發逐位學生配發對外 port 時使用的範圍 | 必填。預設 30000–39999；必須介於 1024 到 65535，且起始不大於結束 |
| 對外入口主機 | 學生在轉發位址「host:port」中看到的主機名稱或 IP | 選填，最長 255 字元 |
| 預設封鎖網段 / IP | 所有機器都不能連到的網段 | 選填，每行一個或以逗號分隔，例如 `192.168.100.0/24` |

表格中「用途」的值：

| 用途 | 意義 |
| --- | --- |
| VM／LXC | 機器的位址，VMID 欄會顯示是哪一台 |
| Gateway VM | 設定中的 Gateway VM IP |
| 閘道 | 設定中的閘道 IP |
| 主系統 | 設定中的主系統 IP |
| 保留 | 保留下來不配發的位址 |
| 班級預留 | 替機器還沒建好的班級先預留的位址 |
| 快速練習預留 | 替快速練習先預留的位址 |

表格上方的三張卡片顯示「子網總 IP」、「可用」與「已分配」。「已分配」包含機器、閘道類位址與各種預留；「可用」才是之後還能配給新機器的數量，歸零後就無法再建立新機器。

## 限制與注意事項

- 只要還有 VM 或 LXC 佔用位址，或還有班級、快速練習的預留，「子網 CIDR」就不能修改。請先刪除這些機器，或等班級建機完成、退回班級後再改。
- 修改子網不會替既有機器重新編號；新的「VLAN ID」也不會回頭改既有機器的網卡。
- 「閘道 IP」、「Gateway VM IP」與「主系統 IP」都必須在子網內、彼此不同，且不能是已配給機器或已預留的位址。
- 封鎖網段不能和實驗室子網重疊，否則機器會連自己的閘道、DNS 與其他機器都擋掉，因此存檔會被拒絕。
- 封鎖網段會變成每台機器的出站丟棄規則，排在允許一般出站流量的規則之前；在 [防火牆](/zh-TW/manual/firewall) 頁會顯示為上鎖、由平台管理的規則。
