# 班級審核

班級審核是管理員核准或駁回老師為整個班級批次建立機器的申請，並追蹤機器建立進度的地方。側欄：審核 → 班級審核。路徑：`/batch-review`。

## 誰可以使用

只有管理員。老師從自己的班級送出批次申請（見[班級設定](/zh-TW/manual/class-setup)與[班級工作頁](/zh-TW/manual/class-workspace)），但無法開啟這頁。

## 開始之前

- 要有老師把班級送出建機，否則**待審核**分頁是空的（**沒有批次申請**）。
- 核准後會立刻開始建立機器，請先確認 PVE 連線與班級使用的範本都已就緒。

## 操作步驟

### 選擇清單

1. 頁面預設停在**待審核**：等你決定的批次。
2. **已通過**包含你核准的批次，也包含**等待中**、**建立中**、**已完成**與**失敗**的批次。
3. **已拒絕**是你駁回的批次。
4. **全部**列出所有批次，包含只會出現在這裡的**已取消**批次。
5. 分頁上的數字是該分頁的筆數。清單會在背景自動更新。

![選擇清單（圖中編號對應上方步驟）](/manual-shots/zh-TW/batch-review/s01.webp)

### 找到批次

1. 在搜尋框（**搜尋批次、申請人或課程**）輸入關鍵字，可比對批次名稱、申請人姓名與信箱、課程名稱、資源類型與狀態。
2. 清單中，學士帽圖示是班級批次，主機圖示是不屬於班級的單一批次。
3. 每列顯示機器台數與申請人，右側是狀態徽章與提交時間，依提交時間由新到舊排列。
4. 同一個班級、同一個狀態的機器節點會併成一列，標題是「班級名稱 · N 個節點」。核准或駁回這一列時，整個班級一起處理。

![找到批次（圖中編號對應上方步驟）](/manual-shots/zh-TW/batch-review/s02.webp)

### 查看批次內容

1. 點清單中的一筆批次，右側面板會顯示：
   - **申請類型**：**班級批次**或**單一批次**。
   - **課程**、**資源類型**（VM／LXC）與 **VM 數量**。
   - **規格 / 摘要**與**作業系統 / 範本**。班級有多個規格或範本不同的機器節點時，會逐一列出。
   - **提交時間**與**申請人信箱**。
   - **建立進度**：進度條以不同顏色標出已建好與失敗的機器，並顯示「已建好 / 總數」；有失敗時下方會顯示「N 台建立失敗」。
   - **批次成員（N）**：每位學生與其機器的 VMID；還沒有機器時顯示該任務的狀態。
2. 面板只顯示你點選的那一筆，清單刷新時不會跳到別筆。

![查看批次內容（圖中編號對應上方步驟）](/manual-shots/zh-TW/batch-review/s03.webp)

### 預覽週期排程

1. 批次有週期排程時，面板會顯示**週期排程**，例如「每週一、三 09:00」，下方附原始規則。
2. 按**查看未來時段**載入接下來的開機時段（開始 ～ 結束），再按一次即可收合。
3. 顯示**沒有排定的時段**代表規則之後不會再有時段。

![預覽週期排程（圖中編號對應上方步驟）](/manual-shots/zh-TW/batch-review/s04.webp)

### 核准批次

1. 點選待審核的批次並確認內容。
2. 可在**審核備註**填寫核准原因。
3. 按**核准**。確認框（**核准批量申請**）會寫出你要核准的對象，例如「「甲班」的 3 個機器節點」。
4. 確認後，系統會立刻在背景開始建立機器。批次會移到**已通過**分頁，狀態依序從**等待中**、**建立中**變成**已完成**（或**失敗**），**建立進度**也會跟著增加。

![核准批次（圖中編號對應上方步驟）](/manual-shots/zh-TW/batch-review/s05.webp)

### 駁回批次

1. 點選待審核的批次。
2. 在**審核備註**寫下原因。
3. 按**駁回**，並在**駁回批量申請**確認框中確認。
4. 駁回不會建立任何機器。班級批次若還沒建出任何機器，班級會退回規劃階段，讓老師修改後重新送出。

![駁回批次（圖中編號對應上方步驟）](/manual-shots/zh-TW/batch-review/s06.webp)

### 追蹤失敗

1. 開啟**已通過**分頁並點選該批次。
2. **建立進度**顯示有幾台失敗，**批次成員**則顯示哪些學生沒有 VMID，以及其任務狀態。
3. 部分失敗由老師在班級工作頁按**重試失敗項目**重新建立。這頁沒有重試按鈕，重試開始後可以在這裡看到進度。
4. 這次建機也會以一筆工作出現在[背景任務](/zh-TW/manual/jobs)，可以在那裡打開詳細資訊。

![追蹤失敗（圖中編號對應上方步驟）](/manual-shots/zh-TW/batch-review/s07.webp)

### 查看過去的審核結果

1. 在**已通過**、**已拒絕**或**全部**點選一筆批次。
2. **審核備註**會顯示備註與審核時間（沒有備註則顯示**未填寫備註**），下方是審核者的信箱。

![查看過去的審核結果（圖中編號對應上方步驟）](/manual-shots/zh-TW/batch-review/s08.webp)

## 欄位與選項

| 欄位 | 意義 | 備註 |
| --- | --- | --- |
| 待審核 | 等待管理員決定 | 只有這個狀態能核准／駁回 |
| 已核准 | 已核准，正在排入建立佇列 | 列在「已通過」 |
| 等待中 | 已排入佇列等待建立 | 列在「已通過」 |
| 建立中 | 正在建立機器 | 列在「已通過」 |
| 已完成 | 所有機器都已完成 | 列在「已通過」 |
| 失敗 | 建立失敗 | 列在「已通過」；看失敗台數 |
| 已駁回 | 已由管理員駁回 | |
| 已取消 | 已撤回 | 只出現在「全部」 |
| 審核備註 | 給老師的說明 | 選填 |

## 限制與注意事項

- 核准後無法在這頁撤銷，確認框是最後一道確認。
- 已被其他人審核過的批次不能再核准或駁回，操作會失敗並顯示錯誤訊息。
- 這頁會載入最新 200 筆批次，另外再載入最多 200 筆待審核批次，所以較舊的待審批次不會被新的擠掉。
- 班級批次已經建出部分機器後才駁回的話，已建好的機器會保留，班級會標為部分失敗，交給老師重試或回收。
