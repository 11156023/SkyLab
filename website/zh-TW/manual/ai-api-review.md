# AI API 審核

審核使用者在 AI API 頁送出的金鑰申請。核准後，系統會立即發給申請者一把以 `ccai_` 開頭的金鑰。側欄：審核 → AI API 審核。路徑：`/ai-api-review`。頁面標題顯示為 **申請審核**。

## 誰可以使用

只有管理員。其他身分的側欄不會出現這一頁，後端也會拒絕其他人的審核操作。

## 開始之前

- 平台的 AI API 對外網址（部署機 `.env` 的 `AI_API_PUBLIC_BASE_URL`）必須已經設定。留空時核准會失敗，不會發出金鑰。
- 使用者在 [AI API](/zh-TW/manual/ai-api) 送出申請。每筆申請都帶有金鑰名稱、申請用途與申請者選擇的有效期限。

## 操作步驟

### 找出需要處理的申請

1. 打開這一頁，預設在 **待審核** 分頁。
2. 切到 **已通過**、**已拒絕** 或 **全部** 可以回顧歷史紀錄。每個分頁上的數字是該狀態的申請數。
3. 清單會自動更新，有新申請時不必重新整理頁面。

![找出需要處理的申請（圖中編號對應上方步驟）](/manual-shots/zh-TW/ai-api-review/s01.webp)

### 閱讀申請內容

每一列顯示 **申請者**（姓名與 Email）、**金鑰名稱**、**用途**、**狀態**、**申請時間** 與 **審核時間**。用途超過 60 個字會被截斷；把滑鼠停在上面可以看完整內容，開啟審核對話框時也會顯示全文。

![閱讀申請內容](/manual-shots/zh-TW/ai-api-review/s02.webp)

### 通過申請

1. 在待審核申請的 **操作** 欄按 **通過**。
2. 在對話框確認申請者、金鑰名稱、申請時間與用途。
3. 選填審核備註，申請者會以審核意見的形式看到它。
4. 按 **確認通過**。

金鑰會立即發放，出現在申請者的 **API 金鑰** 分頁。有效期限（申請時選的那一個）從核准的那一刻開始計算，速率限制為預設的每分鐘 20 次。

![通過申請（圖中編號對應上方步驟）](/manual-shots/zh-TW/ai-api-review/s03.webp)

### 拒絕申請

1. 在待審核申請的 **操作** 欄按 **拒絕**。
2. 在審核備註寫下原因，讓申請者知道要怎麼修改。
3. 按 **確認拒絕**。

申請者會在自己的 **申請紀錄** 分頁看到申請已被拒絕，以及你寫的備註。

![拒絕申請（圖中編號對應上方步驟）](/manual-shots/zh-TW/ai-api-review/s04.webp)

## 欄位與選項

| 欄位 | 意義 | 說明 |
| --- | --- | --- |
| 狀態分頁 | **待審核**、**已通過**、**已拒絕**、**全部** | 每個分頁最多列出最新的 100 筆申請 |
| 審核備註 | 隨審核結果保存、申請者看得到的意見 | 選填，最多 2000 字 |

## 限制與注意事項

- 審核結果無法更改。申請通過或拒絕後，**操作** 欄改為顯示審核備註（沒有備註則顯示「—」），不再有按鈕。
- 審核時不能修改有效期限或速率限制，金鑰會使用申請者選擇的期限。
- 申請的期限不符合申請者目前身分時，核准會被拒絕，例如申請者現在是學生，卻申請了永不過期的金鑰。請拒絕這筆申請，請對方改申請允許的期限。
- 沒有設定 AI API 對外網址時核准會失敗。請先完成設定再核准一次。
- 兩位管理員同時審核同一筆申請時，只有先送出的決定有效，後送出的會收到錯誤。
- 每一次審核都會記錄在稽核日誌。
