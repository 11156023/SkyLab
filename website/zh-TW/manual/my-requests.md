# 我的申請

「我的申請」是申請個人虛擬機或容器、並追蹤每一張申請的地方：包括審核、建立進度，以及現有機器的規格調整與延長到期日申請。側欄：資源 → 我的申請。路徑：`/my-requests`。

## 誰可以使用

所有已登入的使用者。表單依角色略有不同：

- **學生**一律送出預約申請，必須填開始與結束時間，每張申請都由管理員審核。
- **老師與管理員**另外可以選擇「申請模式」：「預約模式」（和學生一樣要審核）或「立即模式」（自動核准，送出後立刻開始建立機器）。他們在作業系統清單中也會看到虛擬機範本與容器範本，並看得到已建立機器的編號。
- 只有管理員會在失敗的申請旁看到「查看錯誤記錄」圖示。

班級與課程機器由老師分配，不需要在這裡申請。

## 開始之前

- 先到[我的資源](/zh-TW/manual/my-resources)確認剩餘配額。表單不會讓你申請超過剩餘的量，機器台數也包含仍在審核中的申請。管理員不受配額限制。
- 準備一段簡短的申請原因（至少 10 個字），讓審核者知道這台機器的用途。
- 不確定怎麼填時，可以打開右下角的 AI 助手描述你的目標。AI 可以幫你填表，但每個欄位仍要由你確認，帳號與密碼也一律由你自己輸入。

## 操作步驟

### 開啟申請表單

1. 按右上角的「申請資源」（還沒有任何申請時則是「立即申請」）。在「我的資源」按「申請資源」也會開啟同一份表單。
2. 會開啟「申請虛擬機 / 容器」表單，右側的摘要卡會隨著填寫即時更新。
3. 不送出就離開時，按「返回」或「取消」。

![開啟申請表單（圖中編號對應上方步驟）](/manual-shots/zh-TW/my-requests/s01.webp)

### 命名並選擇作業系統

1. 輸入「資源名稱」。只允許小寫字母、數字和連字符，且不能以連字符開頭或結尾；離開欄位時，其他字元會被換成連字符（最多 63 個字元）。
2. 打開「作業系統」選一項。清單分成幾組：
   - 「老師／官方提供的環境範本」（只有學生看得到）：已裝好的環境，建立後可直接使用。欄位下方會顯示範本說明與建議規格。
   - 「作業系統映像（虛擬機）」（老師與管理員看到的是「虛擬機範本」）：全新作業系統的虛擬機。
   - 「容器範本（克隆建立）」：只有老師與管理員看得到。
   - 「容器映像檔」：全新作業系統的 LXC 容器。
3. 你的選擇決定要建立「虛擬機」或「LXC 容器」（「一次申請一台，將建立為……」）。標示「（需 GPU）」的項目需要 GPU。
4. 清單載入失敗時，按欄位下方的「重試」。

選擇作業系統之前，平台會依你的申請原因與規格建議虛擬機或容器；選了作業系統之後，就以作業系統為準。

![命名並選擇作業系統（圖中編號對應上方步驟）](/manual-shots/zh-TW/my-requests/s02.webp)

### 設定登入帳號與密碼

選定作業系統後才會出現這些欄位。

1. **虛擬機（Linux）**：輸入「使用者名稱」（例如 `student`）。輸入時會即時檢查命名規則；錯誤會擋下申請，警告只是提醒。
2. **虛擬機（Windows）**：沒有使用者名稱欄位，帳號固定為 **Admin**。
3. **容器**：沒有使用者名稱欄位，帳號固定為 **root**。
4. 輸入「密碼」（至少 8 個字元）。Windows 會另外顯示檢查清單：至少 8 個字元、大寫英文字母／小寫英文字母／數字／符號四類中至少三類，且不可包含「Admin」。
5. 如果範本的密碼無法由平台設定，表單會說明並且不要求填密碼：機器會沿用範本內建的帳號密碼，請向範本建立者取得。

平台不會保存你設定的密碼；忘記時只能到機器的詳情頁重設。

![設定登入帳號與密碼（圖中編號對應上方步驟）](/manual-shots/zh-TW/my-requests/s03.webp)

### 選擇 CPU、記憶體與硬碟

1. 在「硬體資源配置」用拉桿或數字框設定「CPU 核心數」、「記憶體 (RAM)」與「硬碟空間 (Disk)」。選了範本時會先帶入範本的建議規格。
2. 受剩餘配額限制時，提示會寫「依剩餘配額，最多可申請……」，拉桿無法再往上拉。
3. 剩餘配額連最低需求都不夠時，會出現紅字說明是哪一項不足。請先釋放機器，或洽管理員調整配額。

![選擇 CPU、記憶體與硬碟（圖中編號對應上方步驟）](/manual-shots/zh-TW/my-requests/s04.webp)

### 選擇 GPU（需要時）

只有作業系統標示「（需 GPU）」或範本要求 GPU 的虛擬機，才會出現「GPU 加速」區塊。

1. 先選好租借時段；GPU 可用性是依該時段計算的。
2. 在「選擇 GPU」挑一張。每個選項都會顯示記憶體與「[可用/總數 可用]」，已滿的 GPU 無法選擇。
3. 若該 GPU 提供多種大小，請選擇「vGPU 規格」；預設為最小可建立的規格。
4. 該時段沒有可用 GPU 時，請改選其他時段或作業系統。

![選擇 GPU（需要時）（圖中編號對應上方步驟）](/manual-shots/zh-TW/my-requests/s05.webp)

### 設定租借時段

1. 在「租借時段」輸入「開始時間」與「結束時間」，兩者都必須在未來三個月內。
2. 也可以使用欄位下方的可用性月曆：它會依你選的規格把日期標成「可申請」、「名額有限」或「已滿」。點一個日期選取單日，再點另一個日期延伸範圍。
3. 月曆載入失敗時，仍可以直接在欄位輸入時間。

老師與管理員選「立即模式」時，這一區改為「立即模式設定」：不需要開始時間，可勾選「無限期 (No end date)」或填寫「結束時間」。

![設定租借時段（圖中編號對應上方步驟）](/manual-shots/zh-TW/my-requests/s06.webp)

### 填寫原因並送出

1. 在「申請原因」說明這台機器的用途（至少 10 個字），文字框下方會顯示字數。
2. 核對右側摘要卡：類型、名稱、作業系統、使用者、核心數、記憶體、硬碟與時段。
3. 按「送出申請」。送出前平台會再檢查一次 GPU 是否仍可用、該時段是否有足夠資源；若不足，會請你改選時段或調整規格。
4. 送出後回到清單，申請狀態為「審核中」。

![填寫原因並送出（圖中編號對應上方步驟）](/manual-shots/zh-TW/my-requests/s07.webp)

### 追蹤申請

表格列出每一張申請，欄位為「資源」、「系統」、「帳號」、「規格」、GPU、「申請原因」、「申請時間」、「預約期間」、「狀態」與「操作」，並會自動更新。

1. 「審核中」：等待管理員審核。
2. 「已核准」：已核准，時段開始時會建立機器。
3. 「開通中」：正在建立機器。
4. 「已開通」：機器已建立，請到[我的資源](/zh-TW/manual/my-resources)使用。
5. 「等待資源釋出」：機器已建立但暫時開不了機（例如 GPU 記憶體不足），平台會持續重試；把滑鼠移到沙漏圖示上可以看到原因。
6. 「開通失敗」／「機器異常」：見下方「重試建立失敗的申請」。
7. 「已拒絕」：把滑鼠移到狀態旁的留言圖示上，可以看到審核者的備註。
8. 「已取消」：你（或系統）已取消這張申請。
9. 「已過期」：在申請核准或機器建立之前，時段就已經結束。

![追蹤申請（圖中編號對應上方步驟）](/manual-shots/zh-TW/my-requests/s08.webp)

### 撤銷申請

1. 在「操作」欄按「撤銷」。
2. 確認「撤銷申請」。撤銷後無法復原。

申請在審核中，或已核准但機器尚未建立時都可以撤銷。機器建好之後，請改到「我的資源」刪除機器，申請也會一併結案。

![撤銷申請（圖中編號對應上方步驟）](/manual-shots/zh-TW/my-requests/s09.webp)

### 重試建立失敗的申請

1. 狀態為「開通失敗」的申請會有「重試」按鈕。
2. 按下後會重新開始建立，狀態會自動更新。

狀態為「機器異常」時，表示機器已建立，但之後出了問題，無法重試：請按「前往我的資源」，在那裡開機或刪除這台機器。

![重試建立失敗的申請（圖中編號對應上方步驟）](/manual-shots/zh-TW/my-requests/s10.webp)

### 套用或撤銷規格調整

有規格調整或延長到期日的申請時，會出現第二張表「規格調整申請」，欄位為「機器」、「變更內容」（例如「CPU 2 → 4 核」或「到期日 … → …」）、「申請原因」、「申請時間」、「套用時間」、「狀態」與「操作」。

1. 規格調整顯示「已核准 · 待套用」時，按「套用」並確認「關機並套用」。執行中的虛擬機會先關機、套用新規格後再自動開機（約 1～3 分鐘）；容器的 CPU 與記憶體可線上生效。
2. 顯示「套用失敗」或「套用中斷」時，把滑鼠移到圖示上查看原因，再按「重新套用」。
3. 按「撤銷」可以撤回審核中、或已核准但尚未套用的申請。

延長到期日的申請一核准就立即生效，狀態會顯示「已套用」。機器被刪除時，處理中的申請會自動取消（資訊圖示會說明）。

![套用或撤銷規格調整（圖中編號對應上方步驟）](/manual-shots/zh-TW/my-requests/s11.webp)

## 欄位與選項

| 欄位 | 意義 | 備註 |
| --- | --- | --- |
| 「申請模式」 | 「預約模式」或「立即模式」 | 只有老師與管理員；學生一律為預約 |
| 「資源名稱」 | 機器的主機名稱 | 必填；小寫字母、數字、連字符；最多 63 個字元 |
| 「作業系統」 | 要用來建立的範本或映像 | 必填；決定是虛擬機還是容器 |
| 「使用者名稱」 | Linux 虛擬機的登入帳號 | Linux 虛擬機必填，需符合命名規則；Windows 為 Admin，容器為 root |
| 「密碼」 | 你自己設定的登入密碼 | 除非範本沿用自己的密碼，否則必填；8–128 個字元；Windows 另套 Windows 規則 |
| 「CPU 核心數」 | 核心數 | 1–8，受剩餘配額限制 |
| 「記憶體 (RAM)」 | 記憶體（GB） | 0.5–32 GB，以 0.5 GB 為一格，受剩餘配額限制 |
| 「硬碟空間 (Disk)」 | 硬碟（GB） | 容器至少 8 GB、虛擬機至少 20 GB（或範本本身大小），最多 500 GB，受剩餘配額限制 |
| 「選擇 GPU」／「vGPU 規格」 | 該時段使用的 GPU | 只在作業系統或範本需要 GPU 時出現 |
| 「開始時間」／「結束時間」 | 租借時段 | 預約模式必填；需在未來三個月內；結束時間要晚於開始時間 |
| 「無限期 (No end date)」 | 不設結束時間的立即申請 | 只限立即模式 |
| 「申請原因」 | 給審核者看的用途說明 | 必填；至少 10 個字 |

## 限制與注意事項

- 預約申請一律由管理員審核；老師與管理員的立即模式申請會自動核准並立即建立。
- 已核准申請的開始時間一到，平台就會建立並啟動機器；在「我的資源」會先以「排程中」／「開通中」的列出現。
- 結束時間一過，機器會被關機且無法再開機，但不會刪除。要繼續使用，請到機器詳情頁（「進階設定 › 生命週期」）申請延長到期日，或重新申請。
- 時段結束時仍在審核中、或已核准卻沒建出機器的申請，會變成「已過期」。
- 機器已刪除或已轉成範本的申請不再列出。
- 每分鐘最多送出 20 張申請。
