# 教學環境

教學環境是每位學生拿到的一組 1～3 台機器，加上機器之間的連線與對外開放的服務。發布後版本就鎖定，班級建機與快速練習都會照這份環境替每位學生各開一套。側欄：教學 → 教學環境。路徑：`/course-template-management`，編輯器在 `/course-template-management/new` 與 `/course-template-management/<id>`。

## 誰可以使用

- **老師**：查看與編輯自己建立的環境。
- **管理員**：查看與編輯所有環境。
- 學生看不到這個頁面，學生是透過班級或[快速練習](/zh-TW/manual/quick-practice)使用已發布的環境。

## 開始之前

- 每台機器的來源可以是已就緒的機器範本（見[機器範本](/zh-TW/manual/templates)），也可以是基礎映像（VM 映像或 LXC 映像）。
- 要用網址開放服務，管理員必須先設定好對外網域（見[網域管理](/zh-TW/manual/domain)）；沒有設定時只能用對外 port。
- 完整的多機流程請參考[多機教學環境 SOP](/zh-TW/guides/multi-machine-environment-sop)。

## 操作步驟

### 瀏覽清單

1. 開啟 **教學 → 教學環境**。
2. 用**全部**、**已發布**、**草稿**依狀態篩選，旁邊的數字是各狀態的數量。
3. 在**搜尋環境名稱或說明**輸入文字篩選。
4. 每一列顯示**環境名稱**、**每位學生的機器**、**資源合計**（CPU 與 RAM）、**版本**、**提供方式**（**正式課程**、**快速練習**或**課程＋快速練習**）、**使用班級**與**狀態**。還沒取名的草稿會顯示為**無環境名稱**。
5. 點整列，或列尾的箭頭，就會在編輯器開啟。

![瀏覽清單（圖中編號對應上方步驟）](/manual-shots/zh-TW/course-templates/s01.webp)

### 建立環境

1. 按**建立教學環境**，編輯器分成**基本資料**與**機器配置**兩步。
2. 草稿每次修改都會自動儲存，可以做到一半先離開。同步失敗時會出現**草稿尚未同步，請重試；此分頁會保留編輯內容。**與**重試**按鈕。
3. 按**返回**回到清單。

![建立環境（圖中編號對應上方步驟）](/manual-shots/zh-TW/course-templates/s02.webp)

### 填寫基本資料

1. 填寫**環境名稱**，老師替班級選環境時看到的就是這個名稱。草稿可以先空著，但沒填就無法發布。
2. 選擇**套用方式**：
   - **只用於正式課程**：建立班級時可以選用。
   - **只用於快速練習**：出現在快速練習頁。
   - **正式課程與快速練習**：兩邊都會出現。
3. 在**環境用途**寫下說明。
4. 在**說明文件**拖曳或選擇一個以上的檔案，上傳與刪除都立即生效。全新的環境要等第一次自動儲存、建立起來後才能上傳（**環境建立後才能上傳文件。**）。點檔名可以下載，點 **×** 經確認後移除。
5. 按**查看機器配置**進入下一步。

![填寫基本資料（圖中編號對應上方步驟）](/manual-shots/zh-TW/course-templates/s03.webp)

### 加入機器

1. 在**機器配置**選擇**來源方式**：
   - **① 選擇既有範本**：在**既有範本**挑一個已就緒的機器範本。
   - **② 新增 VM/LXC 規格**：選**機器類型**（**VM** 或 **LXC**）與**基礎映像**。
2. 按**加入機器**，機器會出現在拓撲圖上並被選取。
3. 重複以上步驟，最多 3 台；拓撲圖右上角顯示 **N / 3 台**。到上限時按鈕會變成**已達上限**。

沒有可用的範本時，畫面會提示範本仍在處理中或轉換失敗，並建議改用**② 新增 VM/LXC 規格**。

![加入機器（圖中編號對應上方步驟）](/manual-shots/zh-TW/course-templates/s04.webp)

### 編輯機器

1. 點拓撲圖上的機器，右側面板顯示它的來源與類型。
2. 修改**名稱**與**角色**。
3. 拖動 **CPU**、**RAM**、**Disk** 滑桿。磁碟只能比來源的大小更大，不能縮小。
4. **移除節點**會連同這台機器的連線與對外服務一起移除。
5. 在拓撲圖上拖曳機器調整位置，位置會跟著草稿一起儲存。

![編輯機器（圖中編號對應上方步驟）](/manual-shots/zh-TW/course-templates/s05.webp)

### 讓機器互通

1. 從一台機器拉線到另一台，或按**新增連線**後選**讓兩台機器互通**。
2. 選擇**從哪台**、**連到哪台**與**方向**：**單向**或**雙向**。
3. 填寫一個以上的 port 與協定（按**新增 port** 增加一列）。
4. 按**加入環境設定**。

每台機器預設都可以上網，不需要另外加。點拓撲圖上的**上網線**可以顯示或隱藏這些對外連線。

![讓機器互通（圖中編號對應上方步驟）](/manual-shots/zh-TW/course-templates/s06.webp)

### 開放服務給外部

1. 從機器拉線到**網際網路**節點，或按**新增連線**後選**開放服務給外部**。
2. 選擇**哪台機器**，再決定**怎麼開放**：
   - **用網址**：填寫**你的服務跑在哪個 port？**，需要時勾選**啟用 HTTPS（使用管理員設定的憑證）**，輸入**網址前綴**並選擇**網址結尾**。開課時每位學生會在前綴後面接上 `-` 與 16 碼亂碼，成為自己的網址。
   - **用對外 port**：填寫機器內的 port 與協定（TCP 或 UDP）。開課時每位學生自動配到一個對外 port。
3. 按**加入環境設定**。服務會畫成一條從網際網路進來的線，機器右上角的標記會顯示對外服務的數量。

![開放服務給外部（圖中編號對應上方步驟）](/manual-shots/zh-TW/course-templates/s07.webp)

### 檢視或刪除連線

1. 點拓撲圖上的線，細節面板會說明它開放了什麼、往哪個方向。
2. 在面板裡刪除。連線無法直接修改，要改就刪掉重拉。

![檢視或刪除連線（圖中編號對應上方步驟）](/manual-shots/zh-TW/course-templates/s08.webp)

### 發布環境

1. 在**機器配置**按**發布**。
2. SkyLab 會檢查名稱、機器數量與連線的 port。有缺漏時會帶你到對應的欄位或分頁並說明原因。
3. 在**發布並鎖定**對話框確認，這個版本就永久鎖定。
4. 畫面會告訴你環境現在可以在哪裡使用（班級管理、快速練習或兩者）。

如果是從建立班級流程過來的（上方會顯示**班級草稿已保存。**），發布後會自動回到建立班級流程，並替你選好這份新環境。

![發布環境（圖中編號對應上方步驟）](/manual-shots/zh-TW/course-templates/s09.webp)

### 修改已發布的環境

1. 開啟環境。在**基本資料**仍可修改**環境名稱**、**套用方式**與**環境用途**，也能管理**說明文件**。
2. 按**儲存基本資訊**才會送出；已發布的環境不會自動儲存。
3. **查看機器配置**會以唯讀方式顯示凍結的拓撲圖。要改機器就另外建立一份環境。

![修改已發布的環境（圖中編號對應上方步驟）](/manual-shots/zh-TW/course-templates/s10.webp)

### 刪除環境

1. 點列尾的垃圾桶圖示。
2. 在**刪除「`<name>`」？**確認。只有從未被班級或練習使用過的環境可以刪除，且無法復原。

![刪除環境（圖中編號對應上方步驟）](/manual-shots/zh-TW/course-templates/s11.webp)

## 欄位與選項

| 欄位 | 意義 | 備註 |
| --- | --- | --- |
| 環境名稱 | 選擇環境時看到的名稱 | 發布時必填，最多 255 字 |
| 套用方式 | 發布後提供到哪裡 | **只用於正式課程**、**只用於快速練習**、**正式課程與快速練習** |
| 環境用途 | 說明 | 最多 2000 字 |
| 說明文件 | 附在環境上的檔案 | 可一次選多個，每個最大 50 MB |
| 來源方式 | 機器從哪裡來 | **① 選擇既有範本**或**② 新增 VM/LXC 規格** |
| CPU | 每台機器的 vCPU | 1～32（範本本身更多時上限跟著放寬） |
| RAM | 每台機器的記憶體 | 1～64 GB（範本本身更多時上限跟著放寬） |
| Disk | 每台機器的磁碟 | LXC 從 1 GB、VM 從 10 GB 起，最多 1000 GB；不能低於來源大小 |
| 方向 | 機器之間的連線方向 | **單向**或**雙向** |
| 網址前綴 | 每位學生服務網址的開頭 | 小寫英數字與連字號，頭尾不可是連字號，最長 40 字 |

## 限制與注意事項

- 每位學生 1～3 台機器；每份環境最多 6 條機器互通連線與 6 個對外服務。
- 每條連線都要指定 port，不支援 ICMP 這類無埠協定。
- 已被其他連線涵蓋的連線會被拒絕（雙向連線已包含反方向）。
- 同一台機器的同一個 port 只能開放一次。
- 同一個網址前綴可以重複使用，因為每位學生的網址都會接上各自的亂碼。
- 只有草稿可以修改機器與連線。已發布的版本是凍結的，班級會一直使用建立時的版本。
- 不小心離開編輯器（點側欄、重新整理）時，下次進來會還原未儲存的編輯（**已還原上次未儲存的編輯**）。
