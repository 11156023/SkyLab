# 金鑰管理

查看平台上發出的每一把 AI API 金鑰：誰持有、當初申請做什麼、最近一次使用時間、目前是否還能用，並刪除不該再使用的金鑰。側欄：AI 服務 → 金鑰管理。路徑：`/ai-api-keys`。

## 誰可以使用

只有管理員。其他身分的側欄不會出現這一頁。

## 開始之前

- 金鑰只能透過在 [AI API 審核](/zh-TW/manual/ai-api-review) 核准申請來發放，這一頁不能新增金鑰。
- 管理員在這裡（或任何地方）都看不到使用者的完整金鑰，只會顯示金鑰名稱與開頭幾個字元（前綴）。

## 操作步驟

### 切換啟用中與已停用的金鑰

1. 打開這一頁時預設在 **啟用中** 分頁。
2. 選 **已停用** 可以看已過期、已撤銷或已刪除的金鑰；選 **全部** 則不分狀態。
3. 每個分頁上的數字會跟著目前的搜尋與篩選條件變動。

![切換啟用中與已停用的金鑰（圖中編號對應上方步驟）](/manual-shots/zh-TW/ai-api-keys/s01.webp)

### 依身分與建立時間篩選

1. 按 **篩選**。
2. 在 **使用者身分** 勾選 **學生**、**教師** 或 **管理者**（可複選）。
3. 在 **建立時間** 選擇 **全部**、**7 天內** 或 **30 天內**。
4. 條件會立即套用，按鈕上會顯示目前套用的條件數，例如 **篩選 2**。
5. 按 **清除篩選** 移除所有條件。點面板外面或按 Esc 可以關閉面板。

![依身分與建立時間篩選（圖中編號對應上方步驟）](/manual-shots/zh-TW/ai-api-keys/s02.webp)

### 搜尋特定金鑰

1. 在搜尋框輸入金鑰名稱、使用者姓名、Email 或金鑰前綴。
2. 清單會邊打字邊更新。按搜尋框裡的 × 可以清除。

有人回報金鑰外流時，用對方提供的前綴搜尋，就能找出是哪一把。

![搜尋特定金鑰（圖中編號對應上方步驟）](/manual-shots/zh-TW/ai-api-keys/s03.webp)

### 查看金鑰的使用情形

看 **活動** 欄。它顯示這把金鑰最近一次呼叫的時間，從沒用過則顯示 **尚未使用**。長期沒在用的金鑰可以考慮刪除。要看逐筆呼叫，請到 [AI 用量監控](/zh-TW/manual/ai-monitoring)。

![查看金鑰的使用情形](/manual-shots/zh-TW/ai-api-keys/s04.webp)

### 刪除金鑰

1. 在 **啟用中** 分頁找到這把金鑰，按 **操作** 欄的 **刪除**。
2. 看完確認訊息後按 **確認刪除**。

用這把金鑰發出的新呼叫會立即失敗，使用者的 AI API 頁也不再顯示它。已經在進行的呼叫會完成，管理與用量紀錄都會保留。刪除無法復原；使用者如果還需要，請他重新申請。

![刪除金鑰（圖中編號對應上方步驟）](/manual-shots/zh-TW/ai-api-keys/s05.webp)

### 翻頁

清單每頁顯示 50 把金鑰，依建立時間由新到舊排列。超過一頁時，用下方的 **上一頁** 與 **下一頁** 翻頁，旁邊的文字會顯示目前頁數與總筆數。

![翻頁](/manual-shots/zh-TW/ai-api-keys/s06.webp)

## 欄位與選項

| 欄位 | 意義 | 說明 |
| --- | --- | --- |
| 金鑰 | 金鑰名稱與持有者的 Email | |
| 擁有者 | 持有者的姓名 | |
| 申請用途 | 當初申請時寫的用途 | |
| 活動 | 最近一次呼叫的時間 | 從未呼叫時顯示 **尚未使用** |
| 狀態 | **啟用中**、**已停用** 或 **已刪除** | 已停用包含已過期與已撤銷的金鑰 |
| 建立日期 | 金鑰發放的日期 | |
| 操作 | **刪除** | 只出現在啟用中的金鑰，其他列顯示「—」 |

## 限制與注意事項

- **刪除** 只出現在啟用中的金鑰。
- 使用者重新產生過的金鑰，舊的那把會以已停用的狀態和新金鑰並列。
- 頁面開著時清單會自動更新。
- 刪除金鑰會記錄在稽核日誌，標明是代替該使用者進行的操作。
- AI API 背後的模型與上游 LiteLLM 閘道不在這一頁設定，請參考 [LiteLLM 指南](/zh-TW/guides/litellm)。
