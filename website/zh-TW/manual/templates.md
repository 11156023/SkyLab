# 機器範本

範本是由一台已裝好軟體與設定的機器做成的唯讀母版。你可以從它克隆出相同環境的新機器，學生申請機器時也能選用它。側欄：資源 → 機器範本。路徑：`/templates`。

## 誰可以使用

- **老師與管理員**可以開啟這一頁。學生開啟 `/templates` 時會被導到「我的申請」的新申請表單。
- **老師**看得到自己擁有的範本（不論狀態），以及其他人設為「全部可見」的範本。
- **管理員**看得到所有範本。
- 只有**範本擁有者或管理員**可以編輯範本、管理附件、進行更新循環、重新轉換失敗的範本或刪除範本。看得到「就緒」範本的人都可以克隆。
- **學生**不使用這一頁。學生會在申請表單的資源設定裡看到「就緒」且「全部可見」的範本，申請需經過審核。

## 開始之前

- 先準備一台裝好所有軟體與設定的來源機器（VM 或 LXC）。建立範本時這台機器會被關機，之後不再是一般機器，所以請先把要做的事做完。
- 老師只能用自己的機器當來源；管理員可以選任何一台機器。
- 若希望平台能替 VM 範本開出的機器設定登入密碼，請在 VM 裡安裝 cloud-init（Windows 用 cloudbase-init），並在 PVE 上掛好 cloud-init 碟。詳見下方「密碼與 cloud-init」一節。

## 操作步驟

### 從 VM 建立範本

1. 按 **從 VM 建立範本**（在右上角；還沒有任何範本時在頁面中央）。
2. 在 **把 VM 轉為範本** 對話框選擇 **來源機器**。清單會列出每台機器的名稱、VMID 與類型。
3. 填寫 **範本名稱**，並視需要在 **說明** 寫下範本裝了什麼、適合哪些課程。
4. 選擇 **可見範圍**：**私人**（只有你自己）或 **全部可見**（其他老師可以克隆，學生可以在申請表單選用）。
5. 選填：勾選 **這個範本需要 GPU**（只有 VM 範本能設定）、勾選 **自訂預設規格** 並調整滑桿，以及把檔案拖進 **使用手冊 / 附件**。
6. 按 **開始轉換**，看完警告後按 **關機並轉換**。
7. 範本會以 **建立中** 狀態出現在清單上，頁面會自動更新；狀態變成 **就緒** 後就能使用。

轉換時系統會做這些事：把來源機器關機、拔除直通給它的 GPU，並在 PVE 上開啟保護，避免被誤刪。PVE 端不會把它轉成 PVE 範本：這台機器仍以關機且受保護的狀態留在 PVE 上，由 SkyLab 記錄它是範本。它會從你的資源列表移除，原本的 IP 位址與埠轉發規則也會釋放。同時系統會偵測磁碟大小，以及平台能不能設定密碼。

![從 VM 建立範本（圖中編號對應上方步驟）](/manual-shots/zh-TW/templates/s01.webp)

### 從範本克隆機器

1. 打開 **就緒** 範本的 **⋯** 選單，選 **克隆開通**。
2. 選填 **主機名稱**。留空時使用範本名稱；一次克隆多台時會自動加上序號（`-01`、`-02`……）。
3. 設定 **數量**（一次 1 到 50 台）。超出範圍的值會被修正，對話框會告訴你實際送出幾台。
4. 調整 **CPU 核心數** 與 **記憶體 (RAM)**，滑桿的起始值是範本的預設規格。**硬碟空間** 跟隨範本，不能調整。
5. 選填 **登入密碼**（8 到 64 個字元）。留空時由系統產生隨機密碼，可以在資源頁查看。自己填的密碼平台不會保存，忘記時只能重設。如果平台無法替這個範本設定密碼，這個欄位會換成一段說明，克隆機沿用範本內建的帳號密碼。
6. 範本需要 GPU 時，選擇 **GPU**，若該卡有提供，再選 **vGPU 規格**。清單只列出與範本同一個叢集的 GPU；已滿的 GPU 和記憶體不足的規格無法選取。
7. **克隆完成後自動開機** 預設勾選，可視需要取消。
8. 按 **開始克隆**。每台機器都是一個背景任務，進度可在「背景任務」查看；完成後機器會出現在「我的資源」。

![從範本克隆機器（圖中編號對應上方步驟）](/manual-shots/zh-TW/templates/s02.webp)

### 編輯範本或變更可見範圍

1. 打開 **⋯** 選單，選 **編輯 / 可見範圍**。
2. 修改名稱、說明、可見範圍、GPU 需求或預設 CPU 與記憶體。
3. 上傳或刪除附件。在這個對話框裡，上傳與刪除都會立即生效。
4. 按 **儲存變更**。

把可見範圍改成 **私人** 後，申請表單就不再列出這個範本；已經從它開出的機器不受影響。

![編輯範本或變更可見範圍（圖中編號對應上方步驟）](/manual-shots/zh-TW/templates/s03.webp)

### 查看或下載範本的使用手冊

1. 範本有附件時，**⋯** 選單會出現 **使用手冊（n）**。
2. 選它，再按檔案旁的 **下載**。

從這個範本克隆出來的機器，其擁有者也能在該機器的「總覽」分頁下載這些檔案，即使範本之後改成私人也一樣。

![查看或下載範本的使用手冊（圖中編號對應上方步驟）](/manual-shots/zh-TW/templates/s04.webp)

### 用更新循環修改範本

範本本身是唯讀的。要修改範本裡裝的東西：

1. 打開 **就緒** 範本的 **⋯** 選單，選 **開始更新循環**。狀態會變成 **更新循環中**。
2. 系統會完整複製一份範本，產生名為 `tpl-<vmid>-edit` 的暫存母機，並加進你的資源列表。請等它出現在資源列表。
3. 把暫存母機開機、開啟主控台並完成修改。
4. 回到機器範本頁，打開 **⋯** 選單，選 **完成更新（轉為新版）**，再按 **關機並轉換** 確認。
5. 暫存母機會被關機並開啟保護，成為範本的新版本（它的 VMID 成為範本的 VMID），版本號加一，舊版本會被刪除。指定這個範本、但還沒開出機器的申請單會改指向新版本。已經從舊版本克隆出的機器照常可用。

不想改了就選 **取消更新循環**：暫存母機會被刪除，範本回到 **就緒**，內容維持舊版。

![用更新循環修改範本（圖中編號對應上方步驟）](/manual-shots/zh-TW/templates/s05.webp)

### 重新轉換失敗的範本

1. 狀態是 **失敗** 時，範本名稱下方會顯示失敗原因。
2. 排除原因（例如確認來源機器仍存在於 PVE）。
3. 打開 **⋯** 選單，選 **重新轉換**，再按 **關機並轉換** 確認。

![重新轉換失敗的範本（圖中編號對應上方步驟）](/manual-shots/zh-TW/templates/s06.webp)

### 刪除範本

1. 打開 **⋯** 選單，選 **刪除範本**。
2. 按 **確認刪除**。刪除會以背景任務執行。

範本在 PVE 上的機器會連同磁碟一起刪除，附件也會移除，無法復原。以下情況系統會拒絕刪除：

- 正在進行更新循環；
- 還有從這個範本克隆出的機器（訊息會列出它們的 VMID）；
- 還有指定這個範本、已送出或已核准但尚未開出機器的申請單；
- 還有使用這個範本、尚未跑完的批量建立工作；
- 有教學環境（包含草稿與已下架版本）以這個範本為來源。

請先處理這些項目，再重新刪除。

![刪除範本（圖中編號對應上方步驟）](/manual-shots/zh-TW/templates/s07.webp)

## 欄位與選項

| 欄位 | 意義 | 說明 |
| --- | --- | --- |
| 來源機器 | 要做成範本、已裝好環境的 VM 或 LXC | 只在建立時出現。老師只看得到自己的機器，管理員看得到全部 |
| 範本名稱 | 顯示在清單與申請表單上的名稱 | 必填，最多 255 字 |
| 說明 | 範本裝了什麼、用途為何 | 選填，最多 1000 字 |
| 可見範圍 | **私人** 或 **全部可見** | 全部可見時其他老師可以克隆，學生可以在申請表單選用 |
| 這個範本需要 GPU | 用這個範本開出的機器一定要配一張 GPU | 只有 VM 範本能設定，LXC 無法勾選 |
| 自訂預設規格 | 新機器的預設規格 | 1 到 8 核心；0.5 到 32 GB，每格 0.5 GB。不勾選時沿用來源機器的 CPU 與記憶體 |
| 使用手冊 / 附件 | 給範本使用者的檔案 | 最多 10 個，單檔 50 MB：PDF、Markdown、純文字、Word、PowerPoint、Excel、OpenDocument、ZIP、PNG、JPG、WebP、GIF、MP4。建立時會在轉換開始後才上傳 |
| 主機名稱 | 克隆機的名稱 | 只在克隆時出現。選填，最多 63 字元 |
| 數量 | 要克隆幾台 | 只在克隆時出現。1 到 50 |
| 登入密碼 | 寫進克隆機的密碼 | 只在克隆時出現。選填，8 到 64 個字元。平台無法設定密碼時不顯示 |
| GPU／vGPU 規格 | 配給每台克隆機的 GPU | 只在克隆時出現，範本需要 GPU 時才顯示 |
| 克隆完成後自動開機 | 克隆完成後是否自動開機 | 只在克隆時出現，預設開啟 |

清單的欄位依序是 **名稱**、**VMID**（在 PVE 上的編號）、**類型**（`qemu` 是 VM，`lxc` 是容器）、**狀態**、**可見範圍**、**版本**（每完成一次更新循環加一）與 **操作**。

## 密碼與 cloud-init

建立範本時，以及每次完成更新循環時，SkyLab 都會檢查能不能把登入密碼寫進從這個範本開出的機器：

- LXC 範本：一律可以。
- VM 範本：VM 必須在 PVE 上有 cloud-init 碟，而且 guest 裡裝了 cloud-init（Windows 是 cloudbase-init），才可以。

不行時，範本會顯示 **密碼無法由平台設定** 標籤。範本照樣能用：從它克隆或申請出的機器會沿用範本裡原本的帳號密碼，你需要告訴使用者帳密是什麼。要解除這個標籤，請透過更新循環在範本裡裝好 cloud-init；完成更新時會重新檢查。

**Windows 範本** 使用 cloudbase-init，它設定的是固定帳號 `Admin` 的密碼。替 Windows 機器自訂的密碼必須符合 Windows 的複雜度規則：大寫字母、小寫字母、數字、符號與其他文字這幾類中至少包含三類，而且不能含有帳號名稱 `Admin`。不符合時申請會被擋下，因為 Windows 會拒絕這組密碼，機器開得起來卻沒人登得進去。系統產生的密碼本來就符合這些規則。

## 限制與注意事項

- 只有 **就緒** 的範本能克隆；其他狀態下 **克隆開通** 會呈灰色。
- 名稱旁出現 **PVE 不存在** 表示 PVE 已找不到這個範本的機器，可能被人手動刪除；從它克隆或申請都會失敗。
- 克隆會以實際要開出的規格（沒調整時就是範本的預設規格）檢查你的資源配額。
- 只有 VM 範本的克隆機能配 GPU，而且只能用範本所在叢集的 GPU。
- 範本處於 **建立中** 或 **更新循環中** 時，清單每隔幾秒自動更新一次；其他時候每 30 秒更新一次。
- 更新循環期間不要自己刪掉暫存母機。暫存母機不見時，**完成更新** 會被拒絕，請改用 **取消更新循環**。
- 完成更新失敗時，範本會停在 **更新循環中**，名稱下方顯示錯誤。你可以再按一次 **完成更新**，或取消這次循環。
- 完成更新時如果舊版本刪不掉，範本仍會以新版本回到就緒，名稱下方會顯示警告。
