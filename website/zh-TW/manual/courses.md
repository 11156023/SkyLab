# 課程

學生端的課程頁面：列出你加入的課程、單一課程的每週任務、進度與課堂機器，以及單一週次的檢查回饋、機器與教材。側欄：教學 → 課程。路徑：`/courses`、`/courses/<pathId>` 與 `/courses/<pathId>/weeks/<weekId>`。

## 誰可以使用

- **學生**：所屬的每個班級都透過這些頁面上課。
- **管理員**：也可以開啟。
- **老師**：側欄不會出現「課程」，直接開網址也會被導回首頁；老師請改用[班級管理](/zh-TW/manual/class-management)。

## 開始之前

- 沒有自行報名的按鈕。老師把你的帳號（Email）加進班級名單，你就加入了這門課。
- 課程要等學習路徑發布後才會出現在清單裡。班級第一次進入「可以上課」狀態時會自動發布；老師也可以在[課程管理](/zh-TW/manual/course-cms)手動發布或下架。
- 課堂機器要等管理員審核通過、機器建好之後才會出現。

## 操作步驟

### 找到你的課程

1. 在側欄點 **教學 → 課程**，「我的課程」頁每門課是一張票券。
2. 每張票券顯示：
   - 狀態標籤：**正在上課**、**今天稍後**、**可課後練習**、**今天已結束**或**可以開始**（沒有排課）。
   - 課程名稱與授課老師。
   - 老師有設定時，會列出下一堂課的**日期**、**時間**與**教室**。
   - 票根上的條碼與 `4 / 8` 這類計數，後面接**題已完成**（或**全部完成**）。老師還沒發布練習題時顯示**老師還沒發布練習題**。
3. 點票券進入課程。

如果看到**目前沒有課程**，表示你所屬的班級還沒有發布課程。

![找到你的課程（圖中編號對應上方步驟）](/manual-shots/zh-TW/courses/s01.webp)

### 閱讀課程頁

課程頁分成左右兩欄。

1. 左欄**截至今天的所有任務**依時間由舊到新列出這門課的每一週，以及發布到今天為止的任務。每一列顯示週次、標題、日期、檢查項目數；老師有回覆時會加上**老師有回覆**標記。
2. 右欄**本週進度**顯示本週（上課日期在今天或之前的最後一週；學期還沒開始時取第一週）：
   - 上課時間、老師與地點。
   - **檢查通過 N / M 項**，或**這週沒有檢查項目**。
   - 老師的回覆（如果有）。
   - **查看本週**會開啟週次頁。
3. 右欄下方的**你的課堂機器**列出這門課的機器。
4. **返回我的課程**回到課程清單。

![閱讀課程頁（圖中編號對應上方步驟）](/manual-shots/zh-TW/courses/s02.webp)

### 標記本週完成

1. 在**截至今天的所有任務**中，勾選週次列最右側的方框（**標記本週完成**）。
2. 畫面會提示**已將本週任務標記為完成**；再勾一次可以取消。

勾選只是告訴老師你做完了，不會啟動 AI 檢查，也不會改變「檢查通過」的數字。只有包含待完成任務的週次才有這個方框。

![標記本週完成（圖中編號對應上方步驟）](/manual-shots/zh-TW/courses/s03.webp)

### 查看 AI 任務的要求

有些任務沒有掛在某一週底下，這類列不會開啟週次頁，而是在原地展開。

1. 點該列展開。
2. 閱讀**AI 整理的任務重點**與編號的檢查項目。
3. 每個項目旁的標記說明它會怎麼被檢查：**AI 可提供檢查建議**、**AI 輔助＋老師確認**或**老師人工確認**。

![查看 AI 任務的要求（圖中編號對應上方步驟）](/manual-shots/zh-TW/courses/s04.webp)

### 進入課堂機器

1. 在**你的課堂機器**點機器卡。右側文字說明點下去會發生什麼事：
   - **進入機器**：機器正在執行。
   - **啟動並進入**：機器是關機狀態，會先開機。
   - **正在啟動…**：機器正在開機。
   - **環境配置中**：機器還沒建好（顯示**尚未配置**）。
2. 機器原本關機時，SkyLab 會先開機並等它開好。開好之後，容器（LXC）會開啟終端機，虛擬機會開啟主控台。
3. 大約 90 秒後仍在開機時，會提示**機器仍在啟動中，請稍後再試。**，稍後再點一次機器卡即可。
4. 點機器卡旁的**資訊**按鈕，可前往[我的資源](/zh-TW/manual/resource-detail)查看這台機器的完整頁面。

![進入課堂機器（圖中編號對應上方步驟）](/manual-shots/zh-TW/courses/s05.webp)

### 開啟某一週

1. 點**截至今天的所有任務**中的週次列，或**本週進度**裡的**查看本週**。
2. 頁首顯示課程名稱、本週標題、週次與日期；**返回課程**回到課程頁。

![開啟某一週（圖中編號對應上方步驟）](/manual-shots/zh-TW/courses/s06.webp)

### 查看檢查回饋

**檢查回饋**區塊顯示本週每個檢查項目的最新結果。

1. 最上方的**老師回覆**是老師對這一週的留言（一週一則，老師再回覆就換成新的）。
2. 每個檢查項目顯示標題、說明；多機環境還會標出**在「`<machine>`」上檢查**。
3. 右側狀態是**尚無回饋**、**等待檢查**、**檢查中**、**已通過**、**部分完成**、**等待老師確認**、**未通過**、**已取消**或**環境異常，請稍後重新檢查**其中之一。
4. 狀態下方顯示得分（例如 `3 / 3 分`）與評語。

開啟頁面只會顯示結果，不會重新執行檢查。

![查看檢查回饋（圖中編號對應上方步驟）](/manual-shots/zh-TW/courses/s07.webp)

### 使用本週的機器與教材

1. **課堂機器**列出這門課可以使用的所有機器，含角色與 VMID。
   - **開啟網站**：開啟老師以網址發布的服務。
   - `host:port` 項目是轉進機器的對外 port（滑鼠移上去可看到機器內的 port）。只知道 port 時顯示**對外 port N（入口主機請詢問老師）**。
   - **尚未發布網址**：這台機器沒有對外網址或 port。
   - **機器與主控台**：前往我的資源中這台機器的頁面。
2. **本週教材**列出本週的檔案，點檔案會在新分頁開啟。

![使用本週的機器與教材（圖中編號對應上方步驟）](/manual-shots/zh-TW/courses/s08.webp)

## 欄位與選項

| 欄位 | 意義 | 備註 |
| --- | --- | --- |
| 票券狀態 | 這門課今天的狀況 | **正在上課**、**今天稍後**、**可課後練習**、**今天已結束**、**可以開始** |
| 題已完成 | 已完成的練習題數／總題數 | 顯示在票根 |
| 檢查項目 | 本週任務的項目數 | 顯示在每個週次列 |
| 檢查通過 | 本週已通過的檢查項目 | 要等檢查執行後才會變動 |
| 機器文字 | 點機器卡會做什麼 | **進入機器**、**啟動並進入**、**正在啟動…**、**環境配置中** |

## 限制與注意事項

- 只會列出發布日期在今天以前的任務；未來的任務到發布日才會出現。
- 部分資料讀不到時會顯示**暫時無法取得最新資訊**，你仍可直接前往課程或我的資源。
- 週次尚未發布或已被調整時顯示**找不到這週內容**。
- 課程頁沒有手動開關機的按鈕，點機器卡時會視需要自動開機；上課前後的排程開關機由老師設定。
- 這個頁面的導覽進行時會加入一張虛線框、標著**安全模擬**的課程，只用來示範版面，不會儲存任何資料，也不會啟動機器。
