# Prometheus file_sd targets

`vllm.json` is generated by `bash scripts/prepare-ai-stack.sh` from
`vllm-service/models.json` (one target per distinct vLLM upstream) and is
ignored by Git. Prometheus reads `targets/vllm*.json` and reloads changes on its
own; without the file the `vllm` job simply has no targets.
