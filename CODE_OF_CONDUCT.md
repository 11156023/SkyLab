# Code of Conduct

> **English** | [繁體中文](./CODE_OF_CONDUCT.zh-TW.md)

SkyLab adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. Everyone who takes part in the project, in issues, pull requests, reviews and any other project space, is expected to follow it.

## In short

- Be respectful and welcoming, whatever someone's background, experience or role. Students, teachers and administrators all use and build this project.
- Give and accept constructive feedback; critique the code, not the person.
- No harassment, insults, sexualised language or imagery, or publishing other people's private information (including student data, account names or machine addresses from a real deployment).
- Keep discussions on topic and in good faith.

## Reporting

If you experience or witness unacceptable behaviour, contact the maintainers privately through the [SkyLab-tw organisation](https://github.com/SkyLab-tw) on GitHub, or open a private report from the **Security** tab of this repository if the issue also has a security side. Reports are handled confidentially, and the maintainers will respond as described in the enforcement guidelines of the Contributor Covenant.

Security vulnerabilities are not code-of-conduct issues; please report them as described in [`SECURITY.md`](SECURITY.md).
