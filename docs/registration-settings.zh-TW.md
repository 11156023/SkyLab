# 註冊設定

管理員登入後，前往「使用者管理」頁面，可以調整兩個開關：

- **允許自行註冊**：控制登入頁的註冊入口，以及新的信箱註冊和 Google 首次登入自動建立帳號。開啟時不限制信箱網域；關閉後現有帳號仍可登入，管理員仍可手動新增使用者。
- **註冊後需管理員審核**：可獨立開關，關閉註冊時也會保留設定。開放註冊且啟用審核時，任何新帳號完成信箱驗證，或首次以 Google 登入，都會進入「待審核註冊」，包含 NTUB 帳號。管理員核准後才能登入，也可以拒絕。重新開放註冊時沿用當時的審核設定。

即使關閉人工審核，自行填寫信箱的註冊仍須點擊驗證郵件中的連結並設定密碼。切換審核開關只影響之後完成驗證或新建立的帳號；已在待審核清單中的帳號仍需管理員處理。註冊開關要啟用時，後端必須已設定可寄信的 SMTP。Google 帳號的授權範圍由 Google Cloud 的「目標對象」設定決定；若目前是「外部」，一般 Gmail 也能申請 Google 登入。

首次部署或更新後先執行資料庫遷移。未曾在後台儲存設定時，「允許自行註冊」的初始值沿用 `ENABLE_SIGNUP`，但寄信與正式環境的 Turnstile 設定也必須完整；儲存後以後台設定為準。
